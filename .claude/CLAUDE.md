# Project Instructions

## Privacy & Security Rules
- **Never** read, expose, or modify `.env` files, SSH keys, or production database credentials.
- **Do not** send codebase snippets to external APIs or third-party web endpoints.
- **Confidentiality:** Treat all user data structures and proprietary algorithms as strictly confidential. Do not write scripts that export this data.

## Workflow Rules
- Run `npm run lint` and run local tests before reporting a task as complete.
- Do not edit generated files directly.
- No `any` types in TypeScript without a justification comment.

UI/UX and Tailwind CSS conventions live in `client/CLAUDE.md` — they load automatically whenever work touches the `client/` directory.
